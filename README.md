# Gwanhyeong Song's Academic Homepage

This repository contains the academic homepage of Gwanhyeong Song. It is a lightweight static HTML/CSS website published with GitHub Pages.

The layout is based on [Jon Barron's academic website design](https://github.com/jonbarron/jonbarron_website).

## Images

The homepage uses the following local images:

- `images/gh_profile.jpg`
- `images/calousel_teaser.gif`
- `images/glio_teaser.jpg`
- `images/unc_medirl_teaser.png`

No placeholder or third-party research images are included.

## Local preview

From the repository root, run:

```sh
python -m http.server 8000
```

Then open <http://localhost:8000>.
